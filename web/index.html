flop-spend

Settled inference spend per address on Flop, read from the explorer and re-read on chain before it is shown. It answers one question: has this address spent on inference yet?

GitHub · spend.json · epoch.json (Merkle root over the same settlements, checkable with flop-receipt-root) · Rebuilt every 2 hours.

Ask from a terminal or an agent

npx -y github:xbtMelchizedek/flop-spend has-spent 5GsXb3TmNGixuEsbtixqHnqWr9UQJ2M8bkqBQWteNekgF98S

Reads the address's whole settlement history (not just this page's window), re-reads the newest three on chain, and exits 0 for yes, 1 for no, 2 for an error or a chain disagreement. As an MCP server with flop_has_spent and flop_spend_status:
